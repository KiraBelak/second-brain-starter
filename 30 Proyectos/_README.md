# 30 Proyectos

Trabajo con entregable y fecha de cierre. Si puedes decir "ya terminé", es un proyecto.
Cada proyecto pertenece a un área, y eso se anota en la propiedad `area`.
Cuando termina, la nota se mueve a 90 Archivo.

Ejemplo: [[Evento de aniversario]].
Las decisiones abiertas del proyecto también viven aquí, escritas con la plantilla `Decisión`.

Ejemplo de decisión: [[Elegir sede del evento]].
