# 80 Plantillas

Aquí viven las plantillas. El ajuste de Plantillas de Obsidian apunta a esta carpeta.
Para usar una: abre una nota nueva, abre la paleta con Ctrl/Cmd + P y elige "Plantillas: Insertar plantilla".

- `Persona`, `Proyecto`, `Tarea` y `Área`: las entidades de la bóveda, con las propiedades del curso.
- `Decisión`: una decisión con pregunta, opciones, razón y consecuencias.
- `Diaria`: la nota del día. Notas diarias la usa sola al crear la nota de hoy.
- `Revisión semanal`: el guion de la revisión, que se guarda en `70 Revisiones`.

Las plantillas usan `{{title}}` y `{{date}}`, que el complemento Plantillas reemplaza al insertarlas.
