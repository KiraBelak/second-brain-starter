# 70 Revisiones

Notas de tus revisiones periódicas y las vistas que las apoyan. Empieza por [[Tablero]].

En cada revisión vacías el [[Inbox]]: cada línea se convierte en nota o va a una carpeta, y la captura se mueve a `00 Inbox/procesado/`.
Si no cambia ninguna acción, decisión ni relación, es ruido y no se guarda.

Aquí viven también las bases (archivos `.base`): Personas sin contacto, Proyectos sin cambios en 30 días, Tareas vencidas o bloqueadas y Decisiones.
Para crear una revisión nueva usa la plantilla `Revisión semanal`.
